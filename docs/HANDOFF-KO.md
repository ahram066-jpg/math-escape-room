# 다른 선생님 계정으로 복제하는 방법

이 문서는 현재 사이트를 다른 선생님의 GitHub·Supabase·Sites 계정으로 완전히 분리해 사용하는 절차입니다. 원본 선생님의 학생 데이터와 새 선생님의 학생 데이터는 서로 섞이지 않습니다.

## 1. GitHub 저장소 복제

1. 원본 GitHub 저장소에서 **Fork**를 누릅니다.
2. 새 선생님 계정에 만들어진 저장소를 Codex에서 엽니다.
3. 문제 문구, 이미지, 학교명처럼 필요한 부분을 수정합니다.

공동으로 하나의 저장소를 수정하려는 경우에는 포크 대신 원본 저장소의 공동 작업자로 초대할 수도 있습니다. 하지만 학생 데이터와 배포를 완전히 분리하려면 포크 방식이 더 알맞습니다.

## 2. Supabase 테이블 만들기

1. 새 선생님의 Supabase에서 새 프로젝트를 만듭니다.
2. 왼쪽 메뉴에서 **SQL Editor**를 엽니다.
3. 저장소의 `supabase/schema.sql` 전체를 복사하여 실행합니다.
4. **Table Editor**에 `escape_results` 테이블이 생겼는지 확인합니다.

테이블은 행 수준 보안(RLS)을 켜고 학생 브라우저의 직접 접근을 막습니다. 학생 결과는 사이트 서버만 저장합니다.

## 3. 프로젝트 주소와 서버 비밀키 확인

Supabase 프로젝트 설정의 API Keys 화면에서 다음 두 값을 확인합니다.

- 프로젝트 주소: `https://프로젝트참조.supabase.co` 형식
- 서버 전용 비밀키: `sb_secret_...` 형식

`SUPABASE_SECRET_KEY`는 교사만 관리해야 합니다. 채팅에 붙여 넣거나 GitHub에 커밋하거나 브라우저에서 사용하는 `NEXT_PUBLIC_...` 변수로 만들면 안 됩니다.

## 4. 새 Sites 프로젝트로 배포

현재 `.openai/hosting.json`은 원본 소유자의 Sites 프로젝트를 가리키는 개인 설정이라 GitHub에는 포함되지 않습니다. 새 선생님의 작업 공간에서는 `.openai/hosting.template.json`의 내용을 복사해 `.openai/hosting.json`을 만든 뒤, Codex에 다음과 같이 요청합니다.

> 이 저장소를 내 계정의 새 Sites 프로젝트로 배포하고, Supabase 환경 변수 등록 방법도 안내해 줘.

새 Sites 프로젝트가 만들어지면 배포 환경 변수에 다음 값을 등록합니다.

| 이름 | 값 | 공개 여부 |
|---|---|---|
| `SUPABASE_URL` | 새 Supabase 프로젝트 주소 | 서버 환경 변수 |
| `SUPABASE_SECRET_KEY` | 새 Supabase 서버 비밀키 | 반드시 비밀값 |
| `RESULTS_STORAGE` | `supabase` | 서버 환경 변수 |

원본 D1과 Supabase에 잠시 함께 저장하며 비교하려면 `RESULTS_STORAGE`를 `dual`로 설정할 수 있습니다. 확인이 끝나면 `supabase`로 바꾸세요.

## 5. 정상 연결 확인

1. 배포된 사이트에서 테스트 학생 정보로 방탈출을 완료합니다.
2. 결과 화면에서 활동 소감을 입력하고 제출합니다.
3. Supabase **Table Editor > escape_results**에서 새 행을 확인합니다.
4. 같은 결과를 다시 제출했을 때 `run_id`가 같은 기록이 중복 생성되지 않는지 확인합니다.

주요 저장 항목은 반·번호·이름, 경과 시간, 오답 수, 사용 힌트, 방탈출 점수, 보너스 점수, 최종 점수, 등급, 소감, 완료 시각입니다.

## 문제가 생길 때

- `401` 또는 `403`: 서버 비밀키가 잘못되었거나 공개용 키를 사용했을 가능성이 큽니다.
- `404`: `SUPABASE_URL` 또는 테이블 이름을 확인하세요.
- 테이블이 없음: `supabase/schema.sql`이 오류 없이 실행되었는지 확인하세요.
- 저장은 되지만 화면에 오류가 표시됨: Sites 환경 변수 변경 후 다시 배포했는지 확인하세요.
- GitHub에 비밀키를 올렸다면 즉시 Supabase에서 해당 키를 폐기하고 새 키를 발급하세요.
